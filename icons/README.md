# FocusShield Icons

This folder should contain the following icon files for the extension:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Creating Icons

You can create simple icons using any image editor. The icons should represent a shield or focus-related symbol.

### Quick Solution

For testing purposes, you can:
1. Create a simple colored square image (16x16, 48x48, 128x128)
2. Use an online icon generator
3. Use a free icon from a site like Flaticon or Icons8

### Recommended Design

- Use a shield or target symbol
- Colors: Purple gradient (#667eea to #764ba2) to match the extension theme
- Simple, recognizable design that works at small sizes

Once you have the icon files, place them in this `icons/` folder with the exact names listed above.
